JOBHUNTER — ISTNIEJĄCA APLIKACJA

1. Nie twórz nowego projektu. Czytaj README.md, AGENTS.md i specyfikację 2.0.
2. Node 24 LTS: npm ci, npm run build, npm run doctor.
3. W PowerShell ustaw JOBHUNTER_MODE na AUTO_POLICY i uruchom npm start.
4. W drugim PowerShell ustaw ten sam tryb i wykonaj npm run open.
5. W Ustawieniach zatwierdź materiały/CV, istniejący Gmail/Codex, politykę i osobne prywatne repo historii.
6. Pierwszą historię przygotuj na komputerze z dotychczasową bazą, bez sesji wysyłkowej.
7. Rzeczywiste wysyłki zaczynają się dopiero po świadomym „Start — szukaj i wysyłaj”.
8. Pauza zachowuje sesję; Stop ją kończy. Przed zmianą urządzenia użyj „Stop i przekaż historię”.

Rozwój aplikacji nie zleca rzeczywistych maili, resetowania historii, zmiany nadawcy lub publikacji prywatnych danych. Nie wpisuj sekretów do promptów. Szczegóły i wyniki testów: README.md, docs/HISTORY_SYNC.md, docs/TEST_REPORT.md, docs/TASKS.md.
