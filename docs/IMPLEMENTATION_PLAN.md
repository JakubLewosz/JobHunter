# Plan E0–E2

1. E0: odczyt paczki, pustego repozytorium, wersji lokalnych narzędzi i dokumentacji. Lockfile, diagnostyka i rejestr ograniczeń.
2. E1: Fastify na loopback, lokalna sesja i CSRF, SQLite z migracjami, polski panel, profil/CV, firmy, historia i wersje szkiców.
3. E2: fikcyjny research i wiadomości, trwałe jobs/outbox, polityka w kodzie, kwoty, niepewna wysyłka i reconcile, odpowiedzi, raporty. Testy domenowe/integracyjne i Playwright przez prawdziwy backend/SQLite.
4. Przekazanie: README, raport testów, skrypty Windows i macOS, działający panel.

E3–E5 pozostają kolejnymi etapami: publiczne źródła i CodexRunner, Gmail OAuth, kontrolowana autonomia. Żaden transport live nie jest inicjalizowany w E0–E2.
